How to Test Large File Sync Locally

2024-10-15 · Tips · 5 min read

Testing delta sync with large files locally requires a simple HTTP server. The easiest approach is to run npx http-server . -p 8080 from your static site folder — no installation required.

Once running, point your sync configuration to http://localhost:8080/sitemap.xml. The crawler will discover all URLs listed in the sitemap and begin syncing each page.

For large files (50MB+), ensure your sync client has a sufficient timeout configured. We recommend at least 120 seconds for initial ingestion of very large HTML documents.
