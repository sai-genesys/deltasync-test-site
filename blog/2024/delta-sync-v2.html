Introducing Delta Sync v2.0

2024-11-01 · Engineering · 3 min read

We are thrilled to announce the general availability of Delta Sync v2.0. This release brings significant performance improvements, a redesigned metadata tagging engine, and full sitemap-driven crawling support.

Key highlights include 40% faster sync times on large HTML files, support for nested URL structures up to 5 levels deep, and a new tags.txt sidecar file format for attaching metadata to any synced document.

Upgrade instructions and full release notes are available in our documentation portal. As always, synthetic test data files are provided to help you validate your setup before going live.

v2.1 patch released 2024-12-10: fixes an edge case where pages with no lastmod attribute were incorrectly skipped during incremental sync. Users on v2.0 are encouraged to update immediately.
