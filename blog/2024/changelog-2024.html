Delta Sync 2024 Changelog

Updated 2024-12-10 · All releases

Full release history for Delta Sync throughout 2024. Each entry lists the version, release date, and a summary of changes.

v2.1.0 — 2024-12-10

  • fix Pages with no lastmod attribute were incorrectly skipped during incremental sync
  • fix Sitemap parser now handles CDATA-wrapped loc values
  • feat Added support for sitemap index files (sitemapindex)
  • perf Reduced memory allocation during large batch crawls by 12%

v2.0.0 — 2024-11-01

  • feat Sitemap-driven crawling — crawler now reads sitemap.xml at root instead of following links
  • feat Redesigned metadata tagging engine with tags.txt sidecar support
  • feat Incremental sync using content hash comparison
  • perf 40% faster full sync across all file size categories
  • perf Peak RAM reduced by ~36% on 500-page sites
  • breaking Removed legacy link-following crawler; sitemap.xml is now required
  • breaking Config key crawler.followLinks removed — use sitemap.path instead

v1.9.2 — 2024-09-14

  • fix Fixed race condition when syncing more than 256 pages concurrently
  • fix Corrected priority parsing for sitemap entries with decimal values above 0.9
  • perf Index write batching now flushes every 50 pages instead of every 10

v1.9.1 — 2024-08-02

  • fix HTML entities in page titles were not decoded before indexing
  • fix Relative URLs in sitemap loc elements now resolved against the base URL
  • feat New --dry-run flag shows which pages would be synced without writing to the index

v1.9.0 — 2024-06-18

  • feat Support for changefreq hint — pages marked never are skipped on incremental runs unless forced
  • feat Added JSON export format for index snapshots
  • perf Parallel fetch pool size is now configurable via crawler.concurrency
  • fix Timeout errors during fetch no longer corrupt the index entry for that URL

v1.8.3 — 2024-04-30

  • fix Pages returning HTTP 301 redirects are now followed up to 3 hops
  • fix Fixed incorrect lastmod comparison when server returns dates without time component

v1.8.2 — 2024-03-11

  • fix Crawler no longer retries on HTTP 404 — failure is recorded immediately
  • feat 404 URLs are now flagged in the index with status=not_found for downstream reporting
  • fix Fixed memory leak when processing pages with deeply nested HTML tables

v1.8.1 — 2024-01-22

  • fix Sitemap entries with missing priority defaulted to 0 instead of 0.5
  • fix Corrected encoding issue with non-ASCII characters in page titles
  • perf Startup time reduced by pre-loading the index manifest on init
