Metadata Tagging with tags.txt

2024-12-01 · Engineering · 4 min read

Delta Sync supports a sidecar file format called tags.txt that lets you attach arbitrary key-value metadata to any synced document without modifying the HTML source. Place a tags.txt file in the same directory as the target page and the crawler will merge its contents into the index entry.

The format is one key=value pair per line. Keys are case-insensitive and values are plain strings. Example:

author=Sara Patel
category=engineering
audience=internal
reviewed=true

Tags are indexed alongside the page content and can be used to filter sync results, restrict crawl scope, or drive downstream workflows. A page with audience=internal can be excluded from public index exports without removing it from the sitemap.

If a tags.txt file is updated between syncs, Delta Sync detects the change via file modification time and re-indexes the associated page even if the HTML itself has not changed. This makes tags.txt a lightweight way to trigger re-indexing without touching content.
