API Reference

REST API for Delta Sync v2.x

GET/api/v2/index

Returns the current index summary — total pages, last sync time, and counts by status.

{
  "totalPages": 21,
  "lastSync": "2024-12-10T14:32:00Z",
  "statusCounts": {
    "ok": 20,
    "not_found": 1
  }
}

GET/api/v2/index/pages

Returns a paginated list of all indexed pages.

ParameterTypeDefaultDescription
pageinteger1Page number
pageSizeinteger20Results per page (max 100)
statusstringallFilter by status: ok, not_found

GET/api/v2/index/pages/{url}

Returns the index entry for a single URL, including extracted text, metadata, lastmod, and sync status.

{
  "url": "https://example.com/about/index.html",
  "status": "ok",
  "lastmod": "2024-12-10",
  "lastSynced": "2024-12-10T14:32:00Z",
  "title": "About | DeltaSync Corp",
  "wordCount": 142,
  "tags": {}
}

POST/api/v2/sync

Triggers a sync run. Pass incremental: true to skip unchanged pages.

{
  "site": "https://example.com",
  "sitemap": "/sitemap.xml",
  "incremental": true
}

DELETE/api/v2/index/pages/{url}

Removes a single URL from the index. Does not affect the sitemap or the live page.
