Getting Started

Up and running in under 10 minutes

Home › Docs › Getting Started

1. Install Delta Sync

Delta Sync is distributed as a single binary. Download the latest release for your platform and place it on your PATH.

curl -sSL https://releases.deltasync.io/install.sh | bash

Verify the installation:

deltasync --version
# Delta Sync v2.1.0

2. Configure your sitemap

Delta Sync requires a valid sitemap.xml at the root of your site. At minimum each URL entry needs a loc element:

<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://example.com/index.html</loc>
    <lastmod>2024-12-01</lastmod>
  </url>
</urlset>

3. Run your first sync

Point Delta Sync at your site root and run:

deltasync sync --site https://example.com --sitemap /sitemap.xml

Delta Sync will fetch each URL in the sitemap, extract text and metadata, and write the index to ./deltasync-index/ by default.

4. Run an incremental sync

After the first full sync, subsequent runs are incremental by default. Only pages whose lastmod has advanced since the last sync are re-fetched:

deltasync sync --site https://example.com --sitemap /sitemap.xml --incremental
  1. Delta Sync reads the sitemap and compares each lastmod against the stored index entry.
  2. Pages with a newer lastmod are fetched and re-indexed.
  3. Pages with an unchanged lastmod are skipped.
  4. Pages that return HTTP 404 are flagged with status=not_found in the index.
