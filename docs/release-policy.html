Versioning Scheme

Delta Sync follows semantic versioning (MAJOR.MINOR.PATCH). A MAJOR bump signals a breaking change to the configuration format or crawler behaviour. A MINOR bump adds new features in a backward-compatible way. A PATCH release contains bug fixes only.

Breaking changes are always documented in the changelog with a migration note before the MAJOR release ships.

Upgrade Policy

Minor and patch upgrades are always safe to apply without configuration changes. Before applying a major upgrade, read the migration guide in the changelog and run deltasync validate against your existing config to surface any incompatibilities.

We recommend pinning to a minor version in production and upgrading on a scheduled maintenance window rather than auto-updating to the latest release.

Release Cadence

Patch releases ship as needed, typically within 72 hours of a confirmed bug report. Minor releases ship on a roughly 6-week cycle. Major releases are announced at least 60 days in advance with a public release candidate available for testing.
